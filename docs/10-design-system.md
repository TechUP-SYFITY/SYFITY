### 3.5 브랜드 그라데이션

```
linear-gradient(135deg, #72F4A4 0%, #885CF6 100%)
/* Primary-400 → Accent-500 */
```

로고 마크, 아이콘 배지, 강조 배너 등 브랜드 시그니처 요소에 사용한다.
아이콘 배지에는 글로우를 함께 적용한다: `drop-shadow(0 0 14px rgba(114,244,164,0.3))`.

### 3.6 표면 & 투명도 규칙 (실제 화면 적용값)

다크 배경 위에서 계층은 흰색 투명도 오버레이로 표현한다.

| 용도                  | 값                                                 |
| --------------------- | -------------------------------------------------- |
| App 배경              | `#09090B`                                          |
| 카드/패널 배경        | `rgba(17,17,19,0.8)` (Gray-900 80%)                |
| 입력 필드 배경        | `rgba(255,255,255,0.05)`                           |
| 구분선(divider)       | `rgba(255,255,255,0.07)`                           |
| 경계선(border)        | `rgba(255,255,255,0.09)` ~ `rgba(255,255,255,0.1)` |
| 텍스트 - 기본         | `#FFFFFF`                                          |
| 텍스트 - 보조(라벨)   | `rgba(255,255,255,0.55)`                           |
| 텍스트 - 설명         | `rgba(255,255,255,0.48)`                           |
| 텍스트 - 뮤트/링크    | `rgba(255,255,255,0.35)`                           |
| 텍스트 - 카운터/faint | `rgba(255,255,255,0.25)`                           |
| Primary 버튼 배경     | `rgba(114,244,164,0.3)`                            |
| Primary 버튼 텍스트   | `#09090B`                                          |

## 5. 스페이싱 & 레이아웃

### 5.1 스페이싱 스케일 (4px 기반)

허용 값: **4 · 8 · 12 · 16 · 24 · 32 · 48 · 64px**

| 토큰(Tailwind) | 값   | 용도                      |
| -------------- | ---- | ------------------------- |
| 1              | 4px  | 아이콘-텍스트 간격        |
| 2              | 8px  | 요소 내부 간격            |
| 3              | 12px | 컴포넌트 내 간격          |
| 4              | 16px | 기본 간격                 |
| 6              | 24px | 섹션 내 간격, 카드 gutter |
| 8              | 32px | 섹션 간 간격              |
| 12             | 48px | 큰 여백                   |
| 16             | 64px | 최상위 여백               |

> ❌ 금지 값: 10 · 14 · 18 · 20 · 28 · 36 · 40px — 스케일 일관성을 위해 사용하지 않는다.

### 5.2 반지름 (Radius)

| 토큰 | 값     | 사용처                        |
| ---- | ------ | ----------------------------- |
| sm   | 8px    | 배지, 작은 태그               |
| md   | 12px   | 소형 버튼/칩                  |
| lg   | 16px   | 카드, 입력, 버튼, 모달 (기본) |
| full | 9999px | 아바타, 원형 버튼             |

기본 UI(카드·입력·버튼)는 `16px`(lg)를 사용한다.

### 5.3 Elevation (그림자)

다크 모드에서는 그림자 + 브랜드 글로우로 깊이를 표현한다.

| 용도          | 값                                                                     |
| ------------- | ---------------------------------------------------------------------- |
| 카드/모달     | `0px 40px 100px rgba(0,0,0,0.65), 0px 0px 80px rgba(114,244,164,0.05)` |
| 브랜드 글로우 | `drop-shadow(0 0 14px rgba(114,244,164,0.3))` (아이콘 배지 등)         |

### 5.4 레이아웃 그리드

콘텐츠 컨테이너 최대폭 **1200px**, 중앙 정렬.

| 브레이크포인트 | 기준       | 좌우 패딩     |
| -------------- | ---------- | ------------- |
| Desktop        | 1440px+    | `px-8` (32px) |
| Tablet         | 768–1439px | `px-6` (24px) |
| Mobile         | ~767px     | `px-5` (20px) |

```html
<div class="max-w-[1200px] mx-auto px-5 md:px-6 lg:px-8">…</div>
```

### 5.5 Room 화면 레이아웃 규격

Room 화면은 전체 폭을 사용하며 고정 폭 사이드 패널 + 가변 중앙 영역으로 구성한다.

| 영역          | 규격                         |
| ------------- | ---------------------------- |
| Room Header   | `h-16` (64px)                |
| Mini Player   | `h-20` (80px)                |
| Playlist 패널 | `w-[320px]` 고정             |
| Members 패널  | `w-[280px]` 고정 (min 200px) |
| Chat 패널     | `w-[320px]` 고정             |
| Center 영역   | `flex-1 min-w-[200px]`       |
| 카드 gutter   | `gap-6` (24px)               |

## 8. 모션

| 항목          | 값                                    | 사용처                 |
| ------------- | ------------------------------------- | ---------------------- |
| Duration      | 150ms (fast) / 250ms (base)           | hover, 토스트, 모달    |
| Easing        | ease-out                              | 진입 애니메이션        |
| 트랜지션 대상 | color, background, opacity, transform | 과도한 애니메이션 지양 |

- 실시간 갱신(채팅·참여자)은 레이아웃 급변을 피하도록 부드러운 진입만 적용한다.
- 접근성: `prefers-reduced-motion` 존중.

## 9. 다크/라이트 테마 대응

- MVP는 다크 모드를 기본이자 유일 테마로 제공한다. (`#09090B` 배경 기준)
- 시맨틱 색상 스케일에는 Light 단계 값이 정의되어 있어 향후 라이트 테마 확장이 가능하다.
- 테마는 `:root`(다크) 기준으로 정의하고, 확장 시 `.light` 클래스로 오버라이드하는 구조를 준비한다.

## 10. 적용 가이드

- 색상은 HEX 하드코딩 대신 시맨틱 토큰(`bg-surface`, `text-muted-foreground`, `bg-primary` 등)으로 참조한다.
- 스페이싱은 §5.1 허용 값만 사용하고 금지 값(10·14·18·20·28·36·40px)은 쓰지 않는다.
- 기본 radius는 `16px`(lg)로 통일한다.
- 브랜드 그라데이션·글로우는 시그니처 요소(로고·아이콘 배지)에 한정해 남용하지 않는다.
- 공통 컴포넌트는 Storybook에 등록하여 변형·상태를 문서화한다.
- Figma `0.Foundations`가 토큰 원본이며, 값이 어긋나면 Figma를 기준으로 본 문서를 갱신한다.
